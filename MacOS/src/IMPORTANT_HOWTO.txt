IMPORTANT THINGS TO REMEMBER FOR MAC OS

Copy Paste = command+c and command+v
Delete file = command+backspace (it’s also called the delete button like delete but the other delete button doesn’t work :S )
Got to another desktop = control+left-right-arrows (window management is best with this.) 
How to manage windows = control+up arrow = mission control
How to jump words = option+arrows
Make Folder = mkdir MyFolder
cd .. will back the directory up by one

EXAMPLE STEPS TO BUILD 2024
 Step 1 - Open the terminal in the right folder. Use “finder” to go here: /Users/recombobulator/Projects/Rigonomicon/CMAKE/devkitbase.2024/devkit/plug-ins/bacon Right-click on bacon in path bar, open a terminal here.


Step 2 - Set Environment paths to Maya and Devkit.
export DEVKIT_LOCATION=/Users/recombobulator/Projects/Rigonomicon/CMAKE/devkitbase.2024
export MAYA_LOCATION=/Applications/Autodesk/maya2024
Check it, by running this command: env

Step 3 - Launch CMake commands to compile into debug folder.
cmake -H. -Bbuild.2024 -G Xcode -DCMAKE_OSX_ARCHITECTURES="arm64"
cmake --build build.2024
